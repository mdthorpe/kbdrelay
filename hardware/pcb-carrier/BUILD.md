# kbdrelay carrier board — build & bring-up

Board: **88 × 55 mm**, single-sided (bottom copper only), all through-hole,
**zero wire jumpers**. Two Waveshare ESP32-S3-Zero modules socket onto 0.1"
headers with their USB-C ports overhanging the two short edges, so a keyboard
cable goes in one end and the target cable out the other.

Parts list: `BOM.md` (see the *Purchasing table* section).
Layout is generated by `place.py` + `route.py` — see "Regenerating" at the end.

---

## 1. Fabrication artwork

Everything is in `fab/`:

| File | Use |
|------|-----|
| `print/bottom-copper-MIRRORED-toner.pdf` | **Home etch.** Bottom copper, already mirrored for toner transfer. |
| `print/bottom-copper-asviewed.pdf` | Same artwork un-mirrored, for eyeballing against the CAD view. |
| `print/drill-guide.pdf` | Bottom copper + top silk + actual drill shapes — use to find hole centres. |
| `print/assembly-top-silk.pdf` | Component placement / silkscreen, for stuffing the board. |
| `gerbers/` | Standard Gerbers + Excellon drill (+ drill map) if you'd rather order it. |

**Print at 100 % / "actual size" — no fit-to-page.** The PDFs are 1:1 on A4.
Sanity check after printing: the board outline must measure **88.0 × 55.0 mm**
and the two module pad rows must be **15.24 mm (0.6")** apart.

### The `BOTTOM` check

There is a `BOTTOM` text item in copper near the lower middle of the board. Once
etched, **hold the board copper-side towards you: it must read `BOTTOM`
correctly.** If it reads mirrored, the artwork was flipped — the whole board is
inside-out and every part will be on the wrong side. Bin it and re-transfer.

## 2. Drilling

78 holes, five sizes. Drill from the copper side using `drill-guide.pdf`.

| Drill | Count | Where |
|-------|------:|-------|
| 0.80 mm | 22 | R1–R9, R12 (axial resistors), C2 |
| 0.90 mm | 2 | D2 (LED) |
| 1.00 mm | 48 | U1, U2 (18 each), C1, F1, J1, J2, J3 |
| 1.60 mm | 2 | D1 (Schottky, DO-201AD pads) |
| 3.20 mm | 4 | H1–H4 mounting holes (non-plated) |

The module and fuse pads are deliberately **2.0 mm pads on 1.0 mm drills** —
that leaves a 0.5 mm annular ring, which survives hand drilling, and passes a
0.64 mm square header pin (0.905 mm diagonal) that a 0.762 mm hole will not.
**Have a 1.0 mm bit on hand**; it does the bulk of the work.

There are **no vias and no plated holes**. Every connection is on the bottom
copper; the top side is bare. That means **every component lead is soldered on
the bottom side only** — including the header pins.

## 3. Assembly order

Lowest parts first so the board sits flat while soldering:

1. **R1–R9, R12** — 10 axial resistors, lying flat, 10.16 mm pitch.
   - R1–R5 = **2.2 kΩ** (SPI series), the column at mid-board, top to bottom:
     R5 (DRDY) / R4 (CS) / R3 (MISO) / R2 (MOSI) / R1 (SCK).
   - R6–R9 = **1 kΩ** (UART series), R12 = **1 kΩ** (LED limit).
   - Getting 2.2 k and 1 k swapped will not destroy anything, but SPI will be
     marginal and the LED dim — check the colour bands before soldering.
2. **D1 — 1N5817 Schottky. POLARITY CRITICAL.** The **banded end (cathode) faces
   LEFT**, toward F1 and the modules. The unbanded (anode) end faces right,
   toward J3 / 5 V in. Backwards = no power at all (the safe failure).
3. **D2 — LED. POLARITY.** Cathode (short leg / flat side) faces **right**,
   toward R12. Anode faces left toward the fused rail.
4. **C2** — 100 nF disc, not polarised.
5. **F1** — 60R090 PPTC, not polarised, 5.08 mm pitch, straight leads.
6. **C1 — 470 µF electrolytic. POLARITY CRITICAL.** The **stripe (negative) faces
   RIGHT**, toward C2. Backwards on 5 V will vent it.
7. **J3** (1×2, 5 V in), **J1** and **J2** (1×3 UART) — vertical pin headers.
   - J3: pin 1 = **+5 V** (silk `+`), pin 2 = **GND** (silk `G`).
   - J1/J2: pin 1 = module **TX**, pin 2 = **RX**, pin 3 = **GND**.
     There is deliberately **no VCC pin** on the UART headers.
8. **Module sockets** — four 1×9 female strips, 15.24 mm apart per module.
   Seat them square: solder one end pin, check they sit flat, then do the rest.
9. **M3 hardware** last. Note H3 (bottom-left) sits close to C1's body — use a
   low-profile screw head there.

The modules themselves need four 1×9 **male** strips soldered into their own pad
rows before they can plug in.

### Keep clear

Both modules' onboard **BOOT and RESET buttons must stay reachable with the
modules seated** — that is how firmware gets flashed in situ (there is no
soft-reset header; the shared-GP9 idea was removed by design amendment because
`esp_restart()` cannot enter download mode). Don't add tall parts beside them.

## 4. Bare-board bring-up — do this before seating any module

With **no modules fitted**, meter in hand:

1. **Continuity / isolation**
   - GND is common across J1.3, J2.3, J3.2, C1.2, C2.2, U1 pad 2, U2 pad 2.
   - **U2 pad 1 (TGT 5 V) must be isolated from everything** — the target's USB
     powers TGT, and the two 5 V domains are never merged (FR-011). Only GND is
     shared. Confirm this with a meter; it is the one mistake that could
     backfeed a target machine.
   - SPI pin-to-pin, one series resistor per line:
     U1.7 → R1 → U2.7 (SCK / GP4), U1.8 → R2 → U2.8 (MOSI / GP5),
     U1.9 → R3 → U2.9 (MISO / GP6), U1.10 → R4 → U2.10 (CS / GP7),
     U1.11 → R5 → U2.11 (DATA_READY / GP8).
     Each resistor should read ~2.2 kΩ pin-to-pin and nothing should read short.
   - ⚠ **The two modules' pad rows are mirrored**, because U1 and U2 are rotated
     opposite ways so both USB-C ports face outward. U1's pads 1–9 are its
     **lower** row and 10–18 its upper; U2's pads 1–9 are its **upper** row and
     10–18 its lower. Count pins from the square pad 1 marker on the silkscreen,
     not by row position.
2. **Apply +5 V to J3** (bench supply, current-limited to ~200 mA).
   - Power-good LED lights.
   - Voltage at U1 pad 1 ≈ input − ~0.3 V (the Schottky drop).
3. **Reverse the supply on J3.** Nothing should light, nothing should get warm,
   and no rail should appear. Then put it back the right way round.
4. **Measure F1's in-circuit DC resistance** (expect 0.2–0.5 Ω, up to ~1.2 Ω on
   a cold worst-case part). Write the number down — it feeds the VBUS budget.

## 5. Populated bring-up

Seat both modules (KBD = U1, left; TGT = U2, right), flash the v1 firmware, then
reproduce **AC1–AC5**: typing passes through, Caps/Num/Scroll-Lock LEDs come back
from the target, hot-plug works, watchdog recovers.

Then the fault and margin tests:

- **Keyboard VBUS under load must measure ≥ 4.40 V** with the highest-draw
  keyboard you own. This is the one number that can fail the design: worst-case
  D1 + F1 drop is 0.67 V at 0.58 A, which puts a 5.00 V feed at 4.33 V. If you
  are low, **feed J3 at 5.1–5.25 V** (recommended anyway) or fit an **SB540 /
  SB560** in D1's place — same pads, ~0.1 V less drop.
- High-inrush keyboard enumerates on the first plug-in (this is what C1 is for).
- A brief keyboard-VBUS short trips F1 and it recovers when removed.
- **All power-up orders** work, especially KBD-first → TGT cold-starts later.
- A powered USB-UART debug adapter must not back-power either board.

## Regenerating the layout

The board is scripted; don't hand-edit `kbdrelay-carrier.kicad_pcb`.

```sh
PY=/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3
cd hardware/pcb-carrier
$PY place.py                 # placement, outline, M3 holes, silkscreen, sheet centering
$PY route.py --attempts=60   # B.Cu maze routing + GND pour (deterministic, --seed=7)
kicad-cli pcb drc --format json -o /tmp/drc.json kbdrelay-carrier/kbdrelay-carrier.kicad_pcb
```

`route.py` prints the jumper list — **it should say 0 jumpers.** If a change
pushes it above zero, the wire links it wants are listed by pad pair, and they
belong in this document before anyone etches.
